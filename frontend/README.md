# Callertone frontend

The frontend provides the calls dashboard, individual call analysis, and workspace settings. It is a React and TypeScript app built with Vite and TanStack Start.

## Development

From the project root:

```powershell
npm ci --prefix frontend
npm run dev --prefix frontend
```

The dev server prints its local URL. The backend must be running at `http://localhost:4000`; set `VITE_API_URL` in `frontend/.env` to use another backend URL.

The uploader supports calls up to one hour and 200 MB by default. Long-call pages show transcription, speaker-confirmation, and emotion-chunk progress; users can confirm or change the selected sales-rep speaker.

## Useful commands

```powershell
npm run build --prefix frontend
npm test --prefix frontend
npm run lint --prefix frontend
```

## App structure

- `src/routes/index.tsx` — paginated calls dashboard, search, filters, and uploads.
- `src/routes/calls.$id.tsx` — call verdict, highlights, voice scores, action items, transcript, and audio playback.
- `src/routes/settings.tsx` — workspace review settings.
- `src/lib/api.ts` — typed client for the Express API.
- `src/lib/queries.ts` — shared TanStack Query definitions.
- `src/routes/__root.tsx` — root app shell and query provider.
- `src/routeTree.gen.ts` — generated by TanStack Router; do not edit manually.

Call data flows through the typed API client and TanStack Query. The UI expects the backend routes documented in `../backend/README.md`.
